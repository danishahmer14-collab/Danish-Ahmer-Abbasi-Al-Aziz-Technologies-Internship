## Key Learnings
Deep Learning is a subset of machine learning that uses multi-layered neural networks for complex Calculations,NN are inspired by human brain Interconnected neurons process input data in desired Output,Artificial neurons takes inputs, multiply each by a weight, sum them, add a bias, then pass the result through an activation function, Input layer takes input Hidden layer processes it and Output Layer Generates Output, Weights are learning parameters that Controls how much influence an input has, Bias is a learnable offset that shifts the activation, letting the neuron fire even when inputs are zero, Activation Function intoduces Linearity so that NN can learn Complex Patterns, Relu also known as rectified linear Unit is used to eleminate any negative value also if the value is less then x it oututs x its formula is max(0,x), Sigmoid squashes to (0,1) used for binary outputs/probabilities,softmax is used for multiclass classification it converts a vector of scores into a probability distribution, Forward propagation means passing input through the network layer by layer to get a prediction, Loss functions is used to measure how wrong the prediction is (e.g., MSE for regression, cross-entropy for classification), Backpropagation uses calculus (chain rule) to compute how much each weight contributed to the error, Gradient descent updates weights in the direction that reduces the loss Function,Epochs — one full Cycle through the entire training dataset, Batch size is the number of samples processed before updating weights once, Learning rate controls how big each weight-update step is.
